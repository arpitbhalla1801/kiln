# Code of Conduct

We want kiln to be a welcoming project. Be respectful, assume good faith, and keep feedback about the work, not the person.

Not acceptable: harassment, personal attacks, discrimination, or publishing others' private information.

Report problems by opening a private security advisory on the repository or contacting the maintainer through their GitHub profile. Maintainers may edit or remove contributions and block anyone who breaks these rules.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
